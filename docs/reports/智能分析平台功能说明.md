# 智能数据分析平台功能说明

> 一句话定位：**自然语言驱动的智能数据分析 Agent 平台**——用户输入分析目标，AI 自动完成「意图识别 → 分析计划 → SQL 生成与安全校验 → 受控执行 → 图表展示 → 数据解读 → 推荐追问 → 分析报告」全流程，让不懂 SQL 的业务人员也能自助完成数据分析。
>
> 研究对象：邵阳市政务公开工作；数据来源为邵阳市政府门户**依法公开**的信息公开目录与统计栏目（2026-08-02 起数据范围调整为邵阳市，新宁县源不再纳入）。
> 技术栈：SpringBoot 3 + MyBatis + MySQL 8 + Vue 3 + Element Plus + ECharts + DeepSeek 大模型。

---

## 一、数据层：让数据“可被 AI 理解”

智能分析的前提是数据被结构化、语义化、口径化。平台分四层把原始数据加工成 AI 可直接提问的“指标资产”。

### 1.1 数据采集管道（爬虫 + 结构化抽取）
- **政务信息公开采集**：抓取邵阳市政府门户信息公开目录约 45 个类目，形成 `gov_info_record`（现行库 3890 条）。具备去导航噪音、分页自动发现、栏目树探测、幂等复跑（断点续爬、只增不重）等能力，产出「0 重复 / 0 空标题 / 0 壳页」的干净基线。
- **统计指标结构化管道**：针对「统计月报 / 统计公报 / 统计分析」三类公开内容，自动解析 Excel 月报卡附件、从公报正文抽取指标，沉淀为「期间 × 指标 × 区县」长表 `stat_indicator`（如地区生产总值、财政收入、规模工业增加值及其增速）。支持规则抽取为主、大模型兜底，结果标注 `generatorType` 与置信度便于人工核对。

### 1.2 数据源管理
管理后端可连接的外部数据库（JDBC 连接测试 3 秒超时、失败原因透传），为后续多库分析提供统一入口；当前以平台内置 MySQL 为主。

### 1.3 数据元配置（核心：让 AI “懂”数据）
四张元数据表把数据库结构翻译成 AI 的业务语言：
- **数据集**：业务场景与主表映射（如“邵阳政务信息公开数据”）。
- **数据表**：表结构与业务关系说明。
- **字段语义**：字段的业务含义、语义类型（维度/指标/标识）、可否查询/聚合，防止 AI 对字段望文生义。
- **指标口径**：指标定义与计算口径（如“发文量=信息公开记录数”“GDP=地区生产总值”），并注入 LLM Prompt 使生成 SQL 贴合业务口径。
- **分类管理**：以数据集为单位打标签（政务数据/统计数据/演示数据…），四个管理页用「分类 Tab + 全部」快速切换、按需查看，新增数据默认归入「未分类」。

### 1.4 数据浏览
支持对已注册表进行条件查询与明细浏览（分页），便于人工核对采集结果与指标质量，是“机器抽取 + 人工复核”闭环的一环。

## 二、分析引擎：8 步 Agent 全链路

用户在前端输入一句自然语言（如“邵阳经济趋势”），系统按 8 个可追踪步骤完成分析：

### 2.1 意图识别（INTENT）
识别用户“想干什么”：销售趋势、排名分析、占比结构、统计指标趋势、区县指标排名、通用探索等。规则关键词与 LLM 双路识别，返回**意图名称、置信度、命中关键词、目标表**，例如“统计指标趋势 / 80% / 经济趋势、经济、政务公开 / stat_indicator”。

### 2.2 分析计划生成（PLAN）
把意图细化为可执行计划：**目标表、指标、维度、时间范围、图表类型、执行步骤**（如“地区生产总值（GDP）、增速 × 期间、区县 × 近3年 × 折线图”）。计划即“翻译层”，让后续 SQL 生成有明确的业务蓝图。

### 2.3 Text-to-SQL 生成与安全校验（SQL + VALIDATE）
- **SQL 生成**：规则模板优先，LLM（注入表结构/字段语义/指标口径元数据）按问题自适应生成；生成失败自动纠错重试。
- **安全校验**：9 条硬性规则（危险语句、非白名单表、写入操作拦截等）兜底，`valid/errors` 明确返回，校验不过返回 422 并附错误原因，杜绝 AI 乱写 SQL 的风险。

### 2.4 受控执行（EXECUTE）
只执行通过校验的只读查询，运行时长与结果集落库；结果以列 + 行数据返回，供图表与解读消费。

### 2.5 图表自动推荐（CHART）
按“指标数量 × 维度类型”自动推荐 ECharts 图表（折线/柱状/饼图/表格等），前端直接渲染，无需手工配置。

### 2.6 AI 数据解读（INTERPRET）
基于执行结果由大模型生成业务化解读：找峰值、看结构、比排名、给判断（如“邵东市 GDP 791.54 亿元居首、武冈增速 5.60% 领先”）。**三级降级**：LLM → 规则模板 → 极简摘要，无 key/异常时接口永不失联。

### 2.7 推荐追问（RECOMMENDER）
解读的同时推荐 2~3 个有业务价值的追问（“哪些单位发文最多？”“按月发文量趋势如何？”），点击即可复用会话继续深挖，形成多轮分析闭环。

### 2.8 分析报告生成（REPORT）
一键把本次分析（意图/计划/SQL/执行/解读）重组为结构化的 Markdown 分析报告：概述、数据要点、结论与建议，支持复制与下载，可直接用于汇报。同样 LLM 优先、规则模板兜底。

### 2.9 会话与步骤追踪
每次分析以会话归档，8 个步骤的输入输出、耗时、状态全部落库（`analysis_session / analysis_step / analysis_report`），可回溯每一步“AI 做了什么、为什么”，是演示与验收的关键证据链；同一会话重复分析采用覆盖式产物管理，避免数据膨胀。

## 三、工程保障

| 能力 | 说明 |
|------|------|
| LLM 三级降级 | 意图/解读/报告/SQL 均 LLM 优先、规则兜底，无 `AI_API_KEY` 平台照常可用 |
| SQL 安全双保险 | 生成纠错 + 9 条校验，非法语句不可执行 |
| 幂等与断点续爬 | 采集管道重复运行不产生重复数据，失败可续跑 |
| 三层测试体系 | L1 单元（解析器/生成器/校验器）+ L2 集成（接口数据流）+ L3 端到端（用户场景全链路），当前后端全量测试全绿 |
| 数据合规 | 仅使用依法公开数据，成果报告注明数据来源与口径 |

## 四、典型应用场景

- **趋势分析**：“邵阳经济趋势”“2025 年 1-9 月全市 GDP”——看总量与增速走势。
- **排名分析**：“各区县财政收入排名”“各部门发文量 TOP10”——找头部与差距。
- **结构分析**：“各类目发文量分布占比”——看组成结构。
- **质量分析**：“近30天政务公开发文趋势”“各单位发文时效”——评估信息公开活跃度与时效。
- **自助问数**：科室人员用自然语言直接取数，无需写 SQL；管理端可沉淀指标口径持续优化。
