## 四、新宁县画像（作为 12 区县之一，不单独建源）

- 经济体量：GDP 104.20 亿元，全市第 9，占全市约 5.3%；增速 +4.5% 低于全市平均（+4.96%）。
- 财政：一般公共预算收入 4.95 亿元，全市第 6；增速 -7.66%，好于邵阳县、大祥区、双清区。
- 短板：规上工业增速 +3.27%，全市倒数第 2（仅优于绥宁），工业增长动能偏弱。
- 亮点：居民收入增速 +6.1%（全市第 4）、社零增速 +5.2%（全市第 5），民生与消费端相对稳健。

## 六、2025 年月度趋势（累计口径）

- GDP：1-3月 663.6 亿（+6.3%）→ 1-6月 1,355.5 亿（+6.2%）→ 1-9月 1,974.6 亿（+5.0%），增速逐季回落。
- 规上工业：1-2月 +9.2% → 1-6月 +9.2% → 1-9月 +6.0%，三季度明显放缓。
- 固投：1-6月 -1.6% → 1-9月 **-9.9%**，降幅快速扩大。
- 财政收入：全年各月累计均为负（-6.1% ~ -9.9%）。
- 社零：1-2月 256.1 亿（+5.3%）→ 1-9月 1,182.7 亿（+4.8%）。

## 七、平台使用方法（AI 问数）

后端已接线（2026-08-06），在分析页直接输入即可：

| 问法示例 | 路由 |
|---|---|
| 邵阳经济趋势 | STAT_TREND → `stat_indicator` GDP 趋势（line） |
| 2025年1-9月全市GDP | STAT_TREND → GDP 期间序列 |
| 各区县财政收入排名 | STAT_RANKING → 区县财政收入 bar |
| 规模工业增加值增速趋势 | STAT_TREND → 规上工业增速（LLM 模式自适应） |

- 规则模式（未设 `AI_API_KEY`）：按上面模板给出 GDP 趋势 / 财政排名兜底结果。
- LLM 模式（设 `AI_API_KEY` 后重启后端）：结合元数据按问题自适应生成指标/期间/区域过滤 SQL。
- 管理后台「AI 规则配置」页可查看/调整意图规则与计划配置（本次新增 `STAT_TREND`/`STAT_RANKING`）。

## 八、数据提示与限制

1. **三产占比**：一二三产增加值 value 目前为空（仅增速有值），无法直接算占比；需从公报补增加值绝对值。
2. **规上工业增速双行**：同一期间存在 6.00/5.95 两个来源值（不同 sheet），趋势分析取首行并标注 `×2`。
3. **单位换算**：部分原始值为万元（如区县财政收入 138,308 万元），报告已换算为亿元。
4. **年度缺口**：2023/2024 全市 GDP 待从官方公报补数。
5. **合规**：全部数据来自政府门户依法公开内容；汇报时注明来源与口径。
