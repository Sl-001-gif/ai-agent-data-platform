# AI Agent数据分析平台 页面结构文档
> **技术栈**：Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios + ECharts + Sass
> **布局**：经典后台管理系统布局（左侧菜单 + 顶部导航栏 + 右侧内容区）
> **说明**：本文档基于29张项目截图完整还原，DeepSeek可直接识别并逐页面生成代码

---

## 一、全局公共布局与路由

```

├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│  左侧    │                                                  │

│  菜单    │                                                  │
│          │                                                  │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

# 页面1：系统首页 /home
## 1. 页面路由
`/home`

## 2. 页面整体布局
顶部欢迎Banner + 下方功能引导卡片组

## 3. 模块拆分
### 模块1：顶部欢迎横幅
- 主标题：`管理员，欢迎进入数据分析工作台`
- 描述文本：`在这里配置数据集、字段语义、指标口径和Prompt模板，让Agent能够把业务问题拆解成可执行的数据分析过程`
- 右侧状态标签：`当前阶段：基础能力`

### 模块2：功能入口卡片组（3个卡片并排）
| 卡片 | 标题 | 描述 | 跳转 |
|------|------|------|------|
| 卡片1 | 数据集管理 | 维护可分析的业务数据范围 | `/dataset` |
| 卡片2 | 字段语义 | 补充字段中文名、类型和业务含义 | `/field-semantic` |
| 卡片3 | Agent分析 | 识别意图、生成计划、查询数据并输出报告 | `/agent-plan` |

## 4. 交互逻辑
- 点击功能卡片 → 跳转到对应功能页面
- 页面加载时获取当前用户信息，展示欢迎语

## 2. 页面整体布局

## 3. 模块拆分
### 模块1：左侧会话列表
- 顶部：【新建会话】按钮
- 会话列表项：
  - 会话标题
  - 所属数据集
  - 创建时间
  - 操作：删除
- 支持搜索会话

### 模块2：右侧聊天主区域
- 顶部会话信息栏：会话标题、数据集、模型选择下拉
- 中间聊天消息区：
  - 用户消息气泡（右侧）
  - AI回复气泡（左侧）
  - AI回复内容包含：文字说明 + 可折叠的SQL代码块 + 查询结果表格 + 图表
- 底部输入区：
  - 多行文本输入框
  - 【发送】按钮

## 4. 交互逻辑
- 点击左侧会话 → 右侧加载历史消息
- 新建会话 → 弹出选择数据集弹窗 → 创建空会话
- 发送消息 → 调用AI分析接口 → 流式/完整返回结果
- 支持追问，自动携带上下文

## 一、项目概述

### 1.1 项目名称
**AI Agent 智能数据分析平台**（AI Agent Data Analysis Platform）

### 1.2 项目定位
基于 **Spring AI + Text-to-SQL** 技术的自然语言驱动自助数据分析平台，用户通过自然语言提问即可完成数据查询、可视化分析、报告生成，降低数据分析使用门槛。

### 1.3 核心能力
| 能力模块 | 说明 |
|---------|------|
| 自然语言转SQL | 用户输入业务问题，AI自动生成查询SQL |
| SQL安全校验 | 拦截危险SQL、越权查询，保障数据安全 |
| SQL自动纠错 | 执行报错后AI自动修正并重试 |
| Agent分析计划 | 输入分析目标，AI自动拆解为多步分析任务 |
| 执行全链路追踪 | 每一步执行状态、耗时、错误可追溯 |
| 自动可视化 | 根据数据自动推荐并渲染ECharts图表 |
| AI数据解读 | 自动生成数据结论、业务分析文案 |
| 多轮会话 | 支持上下文连续追问、递进分析 |
| 分析报告 | 一键生成完整结构化业务分析报告 |

### 1.4 目标用户
- **管理员**：配置数据元、AI模型、Prompt模板
- **普通用户（运营/分析师/业务人员）**：使用自然语言进行数据分析

### 3.2 核心数据流
```
用户自然语言提问
    ↓
前端发送请求
    ↓
后端接收 → JWT鉴权
    ↓
意图识别模块（调用大模型 + Prompt模板）
    ↓
SQL生成模块（注入数据集Schema + 字段语义 + 指标口径）
    ↓
SQL安全校验（拦截危险语句、权限校验）
    ↓
执行SQL查询业务数据库
    ↓
查询结果 → 图表推荐算法 → ECharts配置
    ↓
AI数据解读（调用大模型生成分析文案）
    ↓
返回前端：SQL + 数据表格 + 图表 + 解读文案
```

## 八、核心业务流程

### 8.1 单轮AI数据分析流程
```
用户在AI数据分析页面输入问题
    ↓
选择数据集 + 模型
    ↓
【步骤1：意图识别】
调用意图识别Prompt模板 + 大模型
返回：intent（分析类型）、reason、needChart
    ↓
【步骤2：SQL生成】
组装：数据集Schema + 字段语义 + 指标口径 + 用户问题
调用SQL生成Prompt模板 + 大模型
返回：SQL语句、涉及表、涉及字段
    ↓
【步骤3：SQL安全校验】
检查：是否SELECT只读、是否有权限访问表、是否有全表扫描风险
不通过 → 返回错误
    ↓
【步骤4：执行SQL】
查询业务数据库
返回：查询结果数据集
    ↓
【步骤5：图表推荐】
根据维度数量、指标数量、数据类型
推荐：折线图/柱状图/饼图/表格
生成ECharts配置
    ↓
【步骤6：数据解读】
调用数据解读Prompt模板 + 大模型
输入：查询结果 + 业务含义
返回：分析结论文案
    ↓
返回前端展示
```

### 8.2 Agent自动化分析流程
```
用户创建Agent分析计划
输入：分析目标 + 数据集
    ↓
【生成分析步骤】
调用大模型，将目标拆解为N个有序分析步骤
每个步骤包含：步骤名、分析问题、推荐图表
保存到 analysis_step 表
    ↓
【执行计划】
用户点击执行 → 后台异步逐个执行
    ↓
循环执行每个步骤：
    1. 生成SQL
    2. 安全校验
    3. 执行查询
    4. 保存结果
    5. 更新步骤状态 + 耗时
    ↓
全部步骤执行完成
    ↓
可在执行追踪页面查看每一步详情
可生成完整分析报告
```

### 8.3 分析报告生成流程
```
选择已执行完成的Agent计划
    ↓
获取所有步骤的：查询结果 + 图表配置
    ↓
组装报告Prompt：
分析目标 + 所有步骤的数据 + 图表说明
    ↓
调用报告生成Prompt模板 + 大模型
    ↓
返回结构化报告（Markdown/HTML格式）
    ↓
保存报告到 report 表
    ↓
前端渲染报告内容 + 嵌入ECharts图表
```

# 使用说明
1. 生成前端Vue代码：复制单页面原型+完整项目结构文档发给DeepSeek，指令：`根据下面页面原型和完整项目文档，生成Vue3+Element Plus完整页面template+script+css代码`
2. 生成UI原型图：复制单页文字原型，绘图AI指令：`绘制后台管理页面，Element Plus商务蓝白简约风格，严格按照下面文字布局，无多余装饰`
3. 开发顺序：全局Layout → 首页、用户管理 → 元数据配置4页 → AI配置2页 → 智能分析5页
